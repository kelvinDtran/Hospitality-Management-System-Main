# Hospitality Management System

A hospitality management and point-of-sale system built as an Arizona State University project for Ared, serving restaurants and sports stadiums for customers in Africa. The project covered front-of-house ordering and payment, venue operations, and the management views a hospitality operator needs to run service at scale.

The system was built and ran in production. The customer later asked for the source to be withdrawn from open source, so it is no longer hosted here. This repository is kept as a record of the project.

## My role

- Software development: designed and built the application.
- Product and UX design: designed the system and its interfaces.
- Stakeholder communication: the working contact for the business stakeholders, from requirements through delivery.

# Hospitality Management System

A hospitality management and point-of-sale system built as an Arizona State University project for Ared, serving restaurants and sports stadiums for customers in Africa. The project covered front-of-house ordering and payment, venue operations, and the management views a hospitality operator needs to run service at scale.

The source code was handed over to the project's administrators at delivery and is no longer hosted here. This repository is kept as a record of the project.
